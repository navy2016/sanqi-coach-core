# 三棋思维教练 · 复刻规格 V2（SPEC-V2）

> 依据：6 篇原文（`/workspace/docs/articles/1-3`、`4-6`）正文 + 插图像素级 UI 信息。
> 标注：【原文】= 文章明确；【推断】= 合理推导。本文件是 v2 重做的唯一验收依据。

## 1. 产品定位【原文】

三棋（中国象棋 / 国际象棋 / 围棋）**思考教练**，不是对战平台、不是答案工具，是「教练派」：
> 真正教人下棋的工具，不是告诉你该走哪一步，而是逼着你在落子前，把那五个问题在脑子里过一遍。

五个问题：①我有哪些候选走法 ②对方最强回应是什么 ③对方回应后我怎么继续 ④变化结束后局面谁有利 ⑤我是否遗漏将军/吃子/捉子等强制手段。

## 2. 核心机制：假设推演 Preview【原文，最高优先级】

1. 点击己方棋子 → 棋盘高亮**所有合法落点**
2. 点击落点 → **不立即落子**
3. 右侧面板出现「正在替对手寻找最有力的回应……」
4. 约 1~2 秒后展示**变化树**：
   - 候选走法 + 质量（如 `⚠ 可疑（损失 142 分）`）
   - 对方最强应对 + 手段标签（`[威胁]` / `[抢占中心]` / `[捉子]`）
   - 我方推荐应对 + 标签（`[防守]` / `[发展]` / `[主动]`）
   - 再下一层对方应对
   - 对方次选、第三选（各带一层推荐）
5. 用户点「**换一个走法**」→ 重选 → 再分析；或点「**确认这样走**」→ 正式落子
6. 严重失误必须提前警告：「这步给了对手机会」并展示对手如何惩罚

## 3. 五档走法评级【原文】

| 评分损失（厘兵） | 等级 | 落点颜色 |
|---|---|---|
| 0–30 | 最佳 ✓ | 绿 |
| 31–80 | 良好 ✓ | 蓝 |
| 81–180 | 可疑 ⚠ | 黄 |
| 181–350 | 失误 ✗ | 橙 |
| > 350 | 严重失误 ✗✗ | 红 |
| 全局最优 | ★ | 金 |

直接判严重失误的情形【原文】：非将死局面进入被强制将死；无补偿丢失车/炮/马等主要子力；漏掉己方一步杀；允许对方形成明显强制杀棋。

## 4. 三级 AI 难度【原文】

| 难度 | 行为 |
|---|---|
| 入门 | 从前 5 个合理候选中带权选择，避免立即丢大子 |
| 进阶 | 从前 3 个候选中带权选择，多数时候选最优 |
| 挑战 | 始终选引擎最佳走法，更高搜索深度 |

## 5. 功能清单（v0.4.5 基线）【原文】

| 模块 | 要求 |
|---|---|
| 假设推演 | 见 §2，三棋通用 |
| 五档评级 | 见 §3，棋盘落点着色 + 逐手标注 |
| 全局复盘 | 每手引擎重新评分 + 转折点标注 + AI 总结（最该复盘的几步、反复出现的问题、下局建议） |
| AI 棋理讲解 | 两种模式：①「🧑‍🏫 AI 讲解当前局面」②选中棋子后「AI 讲解这枚棋」；流式吐字，0.5s 起首字；讲三件事：对方想干啥、你该干啥、不能干啥 |
| AI 服务设置 | 可填 baseUrl / Key / model（DeepSeek、智谱 GLM、Doubao-Seed-Evolving 均 OpenAI 兼容）；不填则降级为基础提示，不影响下棋 |
| 棋谱教学 | 514 局，六类：启蒙 / 开局 / 中局 / 杀法 / 战术 / 残局；走错提示「和原谱不一致，要不要回到原谱」；可从任意局面「开始训练」 |
| 残局挑战 | 10 个经典排局（野马操田、七星聚会、蚯蚓降龙、千里独行 + 江湖八大精选），明确「红方胜 / 和棋」目标；支持粘贴 FEN 自定义残局 |
| 悔棋 | 一键退回**玩家自己上一步之前**（不是退回 AI 之前） |
| 对局历史 | 关闭 App 再开可续下 |
| 落子音效 | 木质合成音：普通 / 吃子 / 将军 / 终局 四种 |
| 引擎自恢复 | 引擎进程崩溃自动拉起，用户无感 |
| 诊断日志导出 | 一键导出排查日志 |
| 单步思考 / 选择路数 | 候选走法给前三条对比 |
| TTS 播报 | 讲解可朗读 |

## 6. 技术栈【原文 + 推断】

- 桌面：**Rust + Tauri v2**，安装包 ~8MB、内存 ~40MB（对比 Electron 80–150MB）
- 前端：**React + TypeScript**（原文提到「Rust 引擎层 + TS 业务层 + React UI 层」）
- Android：Tauri v2 Android 构建
- Web：浏览器直接可用
- 引擎：**pikafish（中国象棋，原文实锤）**；国象 / 围棋引擎原文未点名【推断：Stockfish / KataGo】
- AI：OpenAI 兼容端点（Doubao-Seed-Evolving / DeepSeek / GLM），**引擎算、AI 只翻译**，AI 不参与判断
- 三层保险：引擎先算 → AI 只讲 → AI 异常降级基础提示，绝不编造

## 8. 验收标准（可勾选）

- [ ] 三棋均可落子、吃子、悔棋、终局判定
- [ ] 点击落点**不立即落子**，先出变化树，可「换走法 / 确认落子」
- [ ] 变化树含：候选质量、对方最强应对、推荐应对、下一层、次选/第三选
- [ ] 五档评级颜色正确，全局最优标 ★
- [ ] 复盘逐手评分 + 转折点 + AI 总结
- [ ] AI 讲解两模式 + 流式 + 未配 Key 降级
- [ ] 三级难度可切换且行为不同
- [ ] 棋谱教学 514 局六类可打谱、走错提示、任意局面开始训练
- [ ] 残局挑战 10 排局 + FEN 自定义
- [ ] 对局历史、音效、引擎自恢复、日志导出
- [ ] 版本号与 Release tag 一致
- [ ] GitHub Actions：单元测试 + 桌面构建 + Android APK 全绿
